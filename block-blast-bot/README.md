# 🎮 Block Blast Bot

بوت يلعب **Block Blast** تلقائياً على هاتف Android عبر USB.

---

## 🎯 المميزات

- ✅ التقاط الشاشة عبر ADB
- ✅ كشف اللوحة 8×8 والقطع الثلاث (Computer Vision)
- ✅ ذكاء اصطناعي لإيجاد أفضل حركة (Heuristics + Lookahead)
- ✅ تنفيذ الحركات تلقائياً
- ✅ حلقة لعب كاملة
- ✅ عرض مرئي للتشخيص

---

## 📋 المتطلبات

| المتطلب | الإصدار |
|---------|---------|
| Python | 3.10+ |
| ADB | أي إصدار حديث |
| Android | 8.0+ |
| كابل USB | يُفضّل USB 3.0 |
